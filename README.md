# Rules

Do not commit directly to main.
Create a new branch for every task.
Use clear commit messages.
Test your code before pushing.
Create a Pull Request before merging.
Have at least one team member review your code.
Resolve merge conflicts before merging.
Delete branches after they are merged.
Keep commits small and focused on one task.
Make sure the project still runs after your changes
